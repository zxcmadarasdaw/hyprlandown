# Чек-лист этапов 2 и 3 (Quickshell: холст, панель, обои)

Проверять на Fedora в сессии Hyprland после `scripts/link-configs.sh --apply`.
Что прислать: отметки ✓/✗ по пунктам и тексты ошибок. Лог Quickshell:
`qs log -c hyprdesk` (или вывод `qs -c hyprdesk`, если запускать из терминала).

## 0. Подготовка

- [ ] `node scripts/test-qs-logic.js` → `Итог: PASS=48 FAIL=0` (если node нет: `sudo dnf install -y nodejs`)
- [ ] `qs --version` → версия **0.2 или новее** (записать в versions.txt)
- [ ] `qs ipc --help` показывает опцию `-c` (если нет — прислать вывод: хоткеи надо будет поправить)
- [ ] `hyprctl configerrors` пустой после входа

## 1. Этап 2: слой фона и ввод

- [ ] При входе видны: обои, панель сверху, два виджета (часы и заметка) в центре экрана
- [ ] Открыть kitty (Super+Enter) поверх виджета: окно над виджетами, клики и ввод в окне работают
- [ ] Клик по пустому месту рабочего стола не забирает фокус клавиатуры у окна
- [ ] Тянуть мышью пустое место → холст двигается; виджеты едут вместе с ним, не «плывут» друг относительно друга
- [ ] Колесо на пустом месте → масштаб вокруг курсора; на панели справа меняется % масштаба
- [ ] Клик по % на панели (или Super+Ctrl+0) → камера в центр, 100%
- [ ] Вне режима редактирования виджет не двигается при попытке его тянуть
- [ ] Super+E → режим редактирования: синие рамки, шапки над виджетами, подсказка снизу
- [ ] Тянуть за шапку → виджет двигается (шаг 8 px); уголок справа снизу → размер
- [ ] В заметке в режиме редактирования можно печатать текст
- [ ] Super+E ещё раз (или Esc, или «готово» на панели) → выход из режима
- [ ] Рабочие пространства на панели: активное выделено, клик переключает

## 2. Этап 2: сохранение позиций

- [ ] Подвинуть виджет, выйти из режима, перезапустить оболочку: Super+Ctrl+R → виджет на месте, камера там же
- [ ] Подвинуть виджет, подождать 1 секунду, убить Hyprland: `pkill -9 Hyprland` (аварийный выход),
      войти снова (будет safe-сессия), выйти, войти в обычную → позиции сохранились
- [ ] Файл `~/.local/state/hyprdesk/canvas.json` содержит запись с именем монитора (`hyprctl monitors` → имя)

## 3. Этап 3: картинки

- [ ] `mkdir -p ~/Pictures/Wallpapers && cp wallpapers/*.svg ~/Pictures/Wallpapers/`
- [ ] Super+W → следующие обои, Super+Ctrl+W → предыдущие
- [ ] Super+Shift+W → сетка превью; стрелки + Enter применяют; Esc закрывает; клик мимо закрывает
- [ ] Обои не двигаются при панорамировании холста
- [ ] Перезапуск оболочки (Super+Ctrl+R) и перелогин → выбранные обои остались
- [ ] `qs ipc -c hyprdesk call wallpaper reset` → встроенный градиент (откат этапа 3)
- [ ] `qs ipc -c hyprdesk call wallpaper status` → печатает gpu, hwdec, папку, число файлов

## 4. Этап 3: видео

Тестовое видео (VP9, 20 с):
`ffmpeg -f lavfi -i "mandelbrot=s=1920x1080:r=30" -t 20 -c:v libvpx-vp9 -b:v 4M ~/Pictures/Wallpapers/test.webm`

- [ ] Проверка декодера отдельно: `mpv --hwdec=vaapi --frames=60 ~/Pictures/Wallpapers/test.webm 2>&1 | grep -i "hardware decoding"`
      → строка `Using hardware decoding (vaapi)` (на NVIDIA: `--hwdec=nvdec`)
- [ ] Выбрать test.webm в сетке → через ~1 с играет видео, панель без ⚠
- [ ] Нагрузка: `top -p $(pgrep -d, mpvpaper)` → CPU mpvpaper единицы процентов, не десятки
- [ ] Открыть окно во весь экран (Super+F) → видео ставится на паузу, CPU около 0
- [ ] Переключиться на картинку → процесс mpvpaper исчез (`pgrep mpvpaper` пусто)
- [ ] Если mpvpaper не установлен: на панели «⚠ Видео-обои не запустились», виден градиент, остальное работает

## Откат

- Этап 2: `git checkout <предыдущий коммит> -- quickshell hypr`, либо убрать `exec-once = $qs` из hyprland.conf.
- Этап 3: `qs ipc -c hyprdesk call wallpaper reset` или удалить `~/.local/state/hyprdesk/wallpaper.json`.
- Полностью: `bash scripts/link-configs.sh --rollback`; аварийно — вход в «Hyprland (safe)».

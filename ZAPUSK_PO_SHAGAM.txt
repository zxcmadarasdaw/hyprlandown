ЗАПУСК ПО ШАГАМ: Hyprland на Fedora (live-флешка или установленная система)
===========================================================================

Как пользоваться:
- Выполняй шаги по порядку. Каждую строку из блока "КОМАНДА" копируй и вставляй в терминал.
- Место, где написано ССЫЛКА_НА_РЕПО, замени на адрес репозитория, который дал владелец проекта.
- Если шаг написан "ПРОВЕРКА", сверь результат с ожидаемым. Если не совпало, остановись и пришли вывод.
- Ничего из блока "НЕ ДЕЛАТЬ СЕЙЧАС" не запускай, пока владелец проекта не проверит скрипты.

Где открыть терминал:
- На live-системе Fedora: меню приложений, поиск "Терминал" (или "Console").
- В установленной системе: то же самое, или сочетание Ctrl+Alt+T.


ШАГ 0. ОБНОВЛЕНИЕ И GIT
-----------------------
Где: терминал, любой сеанс (GNOME в live тоже подходит).

КОМАНДА:
sudo dnf upgrade -y --refresh
sudo dnf install -y git curl unzip

ПРОВЕРКА:
git --version
Должна выводиться версия git.


ШАГ 1. HYPRLAND И БАЗОВЫЕ ПРОГРАММЫ
----------------------------------
Где: терминал.

КОМАНДА:
sudo dnf install -y hyprland kitty fuzzel

ПРОВЕРКА:
Hyprland --version
Должна выводиться версия. Запиши её, она нужна для versions.txt.


ШАГ 2. ЗВУК, ВИДЕО, ДЕКОДИРОВАНИЕ (AMD)
-----------------------------------------
Где: терминал.

КОМАНДА:
sudo dnf install -y wireplumber mpv mesa-va-drivers ffmpeg-free nodejs libva-utils

Видео-обои (этап 3): dnf search mpvpaper. Если есть: sudo dnf install -y mpvpaper.
Если нет: пришли вывод. Проверки этапов 2 и 3: FEDORA_SETUP.txt, шаг 7А.

ПРОВЕРКА:
wpctl status
Должен показать список звуковых устройств (ошибок быть не должно).

NVIDIA на этом шаге НЕ ставим. Это отдельный этап.


ШАГ 3. QUICKSHELL
-----------------
Где: терминал.

КОМАНДА:
dnf search quickshell

ЕСЛИ В ВЫВОДЕ ЕСТЬ quickshell:
sudo dnf install -y quickshell

ЕСЛИ ВЫВОД ПУСТОЙ ИЛИ НЕТ quickshell:
НЕ ставь ничего вручную. Запиши вывод команды и версию Fedora:
cat /etc/fedora-release
и пришли владельцу проекта.

ПРОВЕРКА (если установилось):
quickshell --version


ШАГ 4. СКАЧАТЬ РЕПОЗИТОРИЙ
--------------------------
Где: терминал, в домашней папке.

КОМАНДА:
cd ~
git clone ССЫЛКА_НА_РЕПО hyprland-dotfiles
cd hyprland-dotfiles
ls

ПРОВЕРКА:
ls должен показать папки hypr, scripts, docs и файлы README.md, versions.txt.
Если папки нет, значит ссылка неверная или репозиторий не запушен.


ШАГ 5. ПРОВЕРКА СКРИПТОВ (БЕЗ ИЗМЕНЕНИЙ)
------------------------------------------
Где: терминал, внутри папки hyprland-dotfiles.

КОМАНДА:
bash scripts/test-session-wrapper.sh

ПРОВЕРКА:
В конце должно быть: PASS=18 FAIL=0
Если FAIL не 0, скопируй весь вывод и пришли владельцу проекта.


ШАГ 6. ПРОСМОТР СИМЛИНКОВ (ТОЛЬКО ПРОСМОТР)
-------------------------------------------
Где: терминал, внутри hyprland-dotfiles.

КОМАНДА:
bash scripts/link-configs.sh

Эта команда ничего не меняет, только показывает, что будет сделано.
Пришли владельцу проекта её вывод перед следующим шагом.


ШАГ 7. ПРИМЕНИТЬ СИМЛИНКИ
--------------------------
Где: терминал, внутри hyprland-dotfiles.
ВНИМАНИЕ: делать ТОЛЬКО после того, как владелец проекта подтвердил вывод шага 6.

КОМАНДА:
bash scripts/link-configs.sh --apply

ПРОВЕРКА:
ls -la ~/.config/hypr
Должны быть ссылки на файлы из папки hypr репозитория.

ОТКАТ, если что-то пошло не так:
bash scripts/link-configs.sh --rollback


ШАГ 8. ЗАПУСК HYPRLAND
----------------------
Где: экран входа (не терминал).

1. Выйди из текущей сессии (меню справа вверху, Выйти).
2. На экране входа найди значок шестерёнки или "Сессия".
3. Выбери "Hyprland" и войди.

Если на live-системе выбора Hyprland нет, см. раздел "ЕСЛИ НЕТ HYPRLAND В ВЫБОРЕ" ниже.


ШАГ 9. ПРОВЕРКА КОНФИГА В HYPRLAND
----------------------------------
Где: внутри сессии Hyprland.

1. Нажми Super+Enter. Откроется терминал kitty.
2. В нём выполни:

КОМАНДА:
hyprctl configerrors

ПРОВЕРКА:
Вывод пустой. Если есть текст ошибки, скопируй его целиком и пришли владельцу проекта.

Выход из Hyprland: Super+Shift+E.


ШАГ 10. ОТЧЁТ ВЛАДЕЛЬЦУ ПРОЕКТА
-------------------------------
Пришли:
- cat /etc/fedora-release
- Hyprland --version
- вывод шага 5 (PASS/FAIL)
- вывод шага 6 (что покажет link-configs)
- вывод шага 9 (configerrors), если есть ошибки
- что сработало, что нет


ЕСЛИ НЕТ HYPRLAND В ВЫБОРЕ СЕССИИ
---------------------------------
Значит, файл сессии не установлен. Это шаг 8 установленной системы (install-session.sh),
на live его обычно нет. Запускать Hyprland можно из терминала, но это хуже, чем вход через экран:
- на live-системе из терминала попробуй: Hyprland
- если ошибка, пришли её текст.
Скрипт install-session.sh (только в установленной системе) запускай ТОЛЬКО после проверки владельцем:
НЕ ДЕЛАТЬ СЕЙЧАС: sudo bash scripts/install-session.sh --apply


НЕ ДЕЛАТЬ СЕЙЧАС
----------------
- sudo bash scripts/install-session.sh --apply (до проверки скрипта)
- установка NVIDIA-драйвера (это этап 14)
- любые команды rm, которых нет в этом файле


ПАРОЛЬ SUDO В LIVE
------------------
Если sudo спрашивает пароль и он не принимается, задай пароль командой:
sudo passwd $USER
Потом повтори команду.
